# WAF Testing Tools

## GoTestWAF (Wallarm)

Detection logic testing tool for WAFs. Tests how well a WAF detects various attack patterns.

**Repository:** https://github.com/wallarm/gotestwaf

## Lightbulb Framework

Python-based WAF testing suite for comprehensive evaluation.

**Repository:** https://github.com/lightbulb-framework/lightbulb-framework

## WAFBench (Microsoft)

WAF performance testing tool from Microsoft Research.

**Repository:** https://github.com/microsoft/wafbench

## WAF Testing Framework (Imperva)

WAF testing tool from Imperva.

## Framework for Testing WAFs (FTW)

OWASP CRS project's rigorous WAF rule testing framework.

**Repository:** https://github.com/coreruleset/ftw

## WAFtester

CLI tool for testing WAFs against 197+ vendors, F1/MCC scoring, 70+ evasion techniques.

**Repository:** https://github.com/amaitou/WAFtester
