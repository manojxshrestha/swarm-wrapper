# Wordfence WAF Fingerprint

## Detection Methodology

| Indicator | Pattern |
|-----------|---------|
| Response Body | "Generated by Wordfence" |
| Response Body | "A potentially unsafe operation has been detected" |
| Cookie | `wfvt_` (Wordfence visitor token) |
| Cookie | `wordfence_verifiedHuman` |
| Response Code | 403 with Wordfence block page |

## Example Detection Commands

```bash
curl -s -v https://target.com/ 2>&1 | grep -i "wordfence\|wfvt_\|verifiedHuman"
```
