# AWS WAF Fingerprint

## Detection Methodology

| Indicator | Pattern |
|-----------|---------|
| Cookie | `AWSALB=` (if behind ALB) |
| Header | `X-AMZ-ID` |
| Header | `X-AMZ-REQUEST-ID` |
| Header | `Server: awselb/2.0` |
| Response Code | 403 with "Request blocked" |
| Response Body | "Generated by cloudfront (CloudFront)" if using CloudFront + WAF |

## Example Detection Commands

```bash
curl -s -v https://target.com/ 2>&1 | grep -i "aws\|x-amz\|awselb"
```
