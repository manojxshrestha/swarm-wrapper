# ModSecurity WAF Fingerprint

## Detection Methodology

| Indicator | Pattern |
|-----------|---------|
| Header | `X-Scanner` (when CRS ruleset is active) |
| Header | `Server: Mod_Security` or `Server: NYOB` |
| Response Code | 403 with "ModSecurity Action" in body |
| Response Body | "This error was generated by Mod_Security" |
| Response Body | "mod_security rules triggered" |

## Example Detection Commands

```bash
curl -s -v https://target.com/ 2>&1 | grep -i "mod_security\|modsecurity\|x-scanner"
```
